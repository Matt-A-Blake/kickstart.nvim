*cheat.txt*               Cheatsheet

A cheatsheet with commands unique to this setup and commands I am still learning

Cheetsheet                                                     *CHEAT* *cheat* ~

gt              Next tab
gT              Previous tab
{count}gt       Got to tab page {count}
<leader>ca      Apply quickfix
<leader>d       Close current file
g<              View last shell command output
<leader>sk      Search Keybindings
CTRL-ws         Split window horizontally
CTRL-wv         Split window vertically

Set tabs to 4
`:set tabstop=4`
`:set shiftwidth=4`

Reload a file
`:e`

================================================================================
BUFFERS                                                 *cheat-buffers*

|"|{c}yy          Yank current line to buffer {c}
|"|{c}{count}y    Yank {count} lines to buffer {c}

|"|{c}p           Paste buffer {c} after cursor
|"|{c}P           Paste buffer {c} before cursor

================================================================================
MARKS                                                   *cheat-marks*

|m|{c}            Mark curren position as {c}
|`|{c}            Move cursor to {c}
|'|{c}            Move to the beginning of the line containing mark {c}
|``|              Return to previous context

`:marks`          List marks

================================================================================
CLAUDE CODE                                             *cheat-claudecode*

<leader>ac        Toggle Claude terminal
<leader>af        Focus Claude window
<leader>ar        Resume Claude session
<leader>aC        Continue Claude session
<leader>am        Select model
<leader>ab        Add current buffer to context
<leader>as        Send visual selection (visual mode)
<leader>aa        Accept proposed diff
<leader>ad        Reject proposed diff

CTRL-o            Read Claude history
CTRL-\ CTRL-n     Change modes to allow neovim commands

================================================================================
UPDATING                                                *cheat-updating*

`:help help-writing`    Get help for writing this document
`:helptags ALL`         Rebuild all help
`:helptags .`           Rebuild in current directory

After running `:helptags .` run `:setlocal modifiable` to allow editing the
file again.

Help examples can be found at `/usr/share/nvim/runtime/doc`.
